# Git Learning

这是我的 Git 与 GitHub 学习仓库，用于记录从本地版本管理到 GitHub 协作流程的学习过程。

## 学习目标

- 理解 Git 的基本概念
- 掌握本地仓库的基本操作
- 学会使用 GitHub 保存和展示学习记录
- 学会使用分支和 Pull Request 管理修改
- 养成清晰提交和整理学习过程的习惯

## 学习原则

- 所有 Git 命令由我亲自执行
- 只记录自己真正理解和完成的内容
- 不直接上传未经整理的 AI 对话
- 不上传密码、令牌、私钥和其他隐私信息
