\# 01 Git 基础与本地仓库



\## 本次目标



理解 Git 的基本作用，并创建第一个本地仓库。



\## 完成内容



\- 检查 Git 是否已经安装

\- 创建独立的 Git 练习目录

\- 使用 `git init -b main` 初始化仓库

\- 使用 `git status` 查看仓库状态

\- 创建并提交 `README.md`



\## 我的理解



Git 是安装在电脑上的版本管理工具，可以记录文件的变化历史。



GitHub 是用于保存和展示远程仓库的网站，它和 Git 不是同一个东西。



一个基本的本地提交流程是：



1\. 修改文件

2\. 使用 `git add` 把文件放入暂存区

3\. 使用 `git commit` 保存一个正式版本
